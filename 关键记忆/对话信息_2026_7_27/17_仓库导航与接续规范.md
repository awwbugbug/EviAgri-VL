# 仓库导航与接续规范

- `README.md`：项目定位、结构和路线概览，不承载代理细则。
- `AGENTS.md`：稳定的贡献、测试、命名、安全与远程执行规则。
- `docs/research/CURRENT_STATE.md`：唯一的实时接续入口，记录可信结论、禁区和下一任务。
- 每次开始顺序：检查 Git → 阅读 `AGENTS.md` → 阅读 `CURRENT_STATE.md` → 阅读当前假设/冻结协议。
- 科学协议变化才递增 `protocol_vN`；权限、路径、换行等工程重试只递增 `attempt_NN`。
- 历史 artifacts、数据和服务器输出不搬迁；避免破坏哈希、引用和复现链。
